## 1. 개요

HWPX 문서 용량을 **사용자 PC에서만** 분석·최적화하는 경량 CLI 도구입니다.  
Electron Desktop 앱과 별도이며, **ZIP 압축 해제 후 바로 실행**합니다.  
외부 서버 업로드, 계정, 텔레메트리는 없습니다.

## 3. 사용 방법

1. `hwpx-opt-win-x64.zip`을 **한 번** 압축 해제합니다.  
   (이메일 첨부 수신 시 Windows 보안(MotW) 경고가 뜰 수 있습니다. 사내 공유 폴더에서 직접 받는 것을 권장합니다.)

2. 압축 해제 폴더에서:
   - **`drop-here.bat`** — HWPX **파일** 또는 **폴더**를 끌어다 놓습니다.  
     - 파일 1개 → 원본 옆에 `*.optimized.hwpx` 생성  
     - 폴더 → `<폴더>/optimized/` 아래에 결과 저장  
   - **`hwpx-opt.cmd`** — 명령 프롬프트에서 `analyze`, `optimize`, `batch` 등 (기본 balanced 모드)  
   - **`사용법.txt`** — 상세 안내

3. **원본 HWPX는 수정되지 않습니다.** 결과 파일을 제출·배포하기 전에 직접 열어 확인하세요.

---

## 4. 보안·서명 안내

- 이 ZIP은 **코드서명되지 않은** `node.exe`와 `.bat` 런처를 포함합니다.  
  (기존 Electron Desktop 자체서명 EXE와 **다릅니다**.)
- SmartScreen, 백신, 그룹 정책으로 실행이 차단될 수 있습니다.  
  차단 시 **IT 헬프데스크**에 MotW 해제 또는 allowlist 요청을 하세요.
- **암호화·DRM·전자서명·권한 제한**이 걸린 문서는 최적화하지 않습니다.

---

## 5. 사용 조건 (필독)

> 이 도구는 HWPX 문서를 외부로 전송하지 않고 사용자 PC에서만 처리합니다. 원본 파일은 수정하지 않으며 결과 파일을 별도로 생성합니다. 암호화, DRM, 전자서명, 권한 제한 등 보안 처리된 문서는 최적화하지 않으며, 보안 조치를 해제하거나 우회하지 않습니다.

> 제작/관리: 한강유역수도지원센터 조은상 과장. 비영리 목적의 기관 **내부 사용**만 허용됩니다. 사전 승인 없는 수정, 재배포, 영리 이용, 제작자 표시 제거는 **금지**됩니다.

> 본 소프트웨어는 있는 그대로 제공됩니다. 결과물은 제출·배포·보관 전에 사용자가 직접 확인해야 하며, **원본 보존과 최종 사용 책임은 사용자**에게 있습니다.
