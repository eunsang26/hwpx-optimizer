# 압축 완료 후 처음 화면으로 돌아가기

2026-10-15, Linux/Node 24.13.0, 실제 Electron 42.11.13. 사용자가 승인한 로컬 Playwright로 캡처했다. 모든 입력은 합성 HWPX이며 설정은 별도 XDG 폴더로 격리했다. 최적화와 파일 저장은 실제 앱의 IPC·core·파일 서비스로 수행했으며, 네이티브 파일 선택 대화상자만 합성 입력을 반환하도록 제어했다. 화면마다 저장한 PNG를 직접 검토했다. 캡처와 실행 JSON은 로컬 `.tmp/ui-audit/`에만 보관하며 GitHub로 전송하지 않는다.

상단과 단일·일괄 완료 결과에 `처음으로`를 추가했다. 완료 결과는 사용자가 확인할 수 있게 유지하며 버튼을 눌렀을 때 초기화한다. 처리 중에는 비활성화한다. 현재 문서·일괄 목록·결과·분석·진행 표시를 비우고 파일 선택에 포커스를 옮긴다. 저장 파일과 현재 제출 기준·압축 정책·저장 설정은 유지한다. 이전 재검증·이미지 비교 응답이 새 화면을 덮어쓰지 않도록 결과 동일성도 확인한다.

## 화면과 동작

1. **수정 전 단일 완료 — 개선 필요.** 완료 상태에서 보이는 새 작업·초기화 동작이 없었다. 상단에도 도움말과 설정만 있다.

   캡처: `.tmp/ui-audit/before/reset-2026-10-15-single-before.png`

2. **단일 완료 — 통과.** 800×560에서 상단 `처음으로`가 보이며 결과 영역에도 같은 동작이 있다. 이 검증에서는 제출 기준을 40MB에서 10MB로 변경해 유지 여부를 확인했다. 캡처 간 기준 값 차이는 이 조작 때문이다.

   캡처: `.tmp/ui-audit/reset-2026-10-15/02-single-complete.png`

3. **Enter로 초기화 — 통과.** 결과·목록·분석 표시가 비워지고 `파일 선택`으로 포커스가 이동한다. 유지한 10MB를 초기 화면 안내에도 표시한다. 초기화 전후 합성 입력 폴더의 모든 파일 해시가 같다.

   캡처: `.tmp/ui-audit/reset-2026-10-15/03-single-reset.png`

4. **키보드로 두 파일 재선택 및 일괄 완료 — 통과.** 옮겨진 포커스에서 Enter로 파일 선택을 열고 합성 문서 두 개를 처리했다. 720×520에서도 상단 복귀 버튼이 보인다. 일괄 완료 결과의 `처음으로`도 Enter로 실행했다.

   캡처: `.tmp/ui-audit/reset-2026-10-15/04-batch-complete-minimum.png`

5. **일괄 초기화 — 통과.** 행 수 0, 단일·일괄 결과 숨김, 진행 표시 숨김, 실행 버튼 비활성화와 파일 선택 포커스를 확인했다. 저장 파일은 유지되고 제출 기준은 10MB다.

   캡처: `.tmp/ui-audit/reset-2026-10-15/05-batch-reset-minimum.png`

6. **다음 문서 선택 — 통과.** 파일 선택에서 Enter로 다른 합성 문서를 가져오면 빈 일괄 목록으로 단일 모드 분석이 정상 실행된다. 이전 완료 결과가 다시 나타나지 않는다.

   캡처: `.tmp/ui-audit/reset-2026-10-15/06-next-document-selected.png`

- 전체 Vitest 78개 파일·586개 테스트 통과·1개 건너뛰기, 타입 검사·빌드 통과.
- `npm run desktop:smoke:built`에 실제 화면 초기화, 포커스 복귀, 정책 유지, 저장 결과 바이트 보존 검사를 추가했다.
- 로컬 실행 확인 기록 `.tmp/ui-audit/reset-2026-10-15/checks.json`: 실제 단일·일괄 최적화, Enter 실행, 반복 파일 선택, 최소 창, 원본 해시와 저장 파일 유지, page error 0개.
