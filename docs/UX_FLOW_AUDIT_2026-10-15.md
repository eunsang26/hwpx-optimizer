# 화면과 작업 흐름 개선 — 2026-10-15

OPT-023은 제출 한도 확인 → 단일/일괄 압축 → 저장 결과 확인 → 다음 작업의 흐름을 개선한다. 기존 파란/녹색 카드·게이지·폰트와 파일 처리 기능을 기반으로 수정했다. 전체 HCI·시각 접근성 완료를 뜻하지 않으며 OPT-024·025의 범위는 아래에 구분한다.

## 캡처 및 관찰

변경 전 기준은 `579131f`다. Linux / Node 24.13.0 / Electron 42.11.13에서 승인된 로컬 Playwright로 실제 앱을 실행했다. 새 profile과 합성 HWPX 2개만 사용했고, 전후에 같은 입력 바이트·800×560·압축/한도 조건을 적용했다. 각 PNG를 저장한 뒤 직접 열어 수락하고 관찰을 기록했다. 분석 전환 중의 빈/희미한 프레임은 기각하고 안정된 상태에서 재캡처했다.

전후 9개 화면과 추가 3개 확인의 이미지·단계별 메모·ARIA snapshot·해시는 `.tmp/ui-audit/ux-flow-2026-10-15/`에 있다. `report.md`가 실제 이미지와 전후 메모를 순서대로 표시한다. PNG와 원시 결과는 로컬에만 두고 Git/외부 앱에 업로드하지 않았다. 최종 보완 후 옵션/재계획 화면도 다시 캡처·확인했다.

## 동작과 검증의 구분

- 완료 결과는 실측 상태로 유지하고, 명시적인 `다시 최적화`가 원본 분석·계획으로 돌아간다. 저장 파일은 유지하며 이전 `검증 완료` 문구도 분석 사전 점검으로 초기화한다. 포커스는 하단 실행으로 이동한다.
- 다음 동작은 계획이면 실행, 단일 완료면 파일 열기, 일괄 완료면 폴더 보기, 취소/실패를 포함한 일괄 결과면 처리 결과 확인이다. 후자는 결과 제목으로 이동해 미완료 항목을 확인하게 한다. 처음으로는 저장 결과·설정을 유지하고 파일 선택으로 돌아간다.
- 단일/파일별/합계의 한도와 예상/실측을 구분한다. 합계 게이지는 원본/현재 합계를 기준으로 같은 크기 축을 쓰며, 한도가 축 밖이면 내부의 거짓 위치를 표시하지 않는다. 파일별 통과율은 파일별 상태로 남긴다.
- 그림 정리 옵션은 실제 core 정책에 맞춰 표시했다. `clean-shape-comment`는 생성된 그림 이름/크기 행만 지우고 작성 설명을 보존한다. `strip-metadata`는 JPEG EXIF를 보존하므로 그 작업을 EXIF 전체 삭제로 표시하지 않는다. 작성자/이력 익명화를 제공하지 않는다.

최종 Playwright 실행은 실제 pointer/keyboard와 preload/IPC/main/worker/파일 저장을 거쳐 다음을 확인했다. 원본 SHA256 불변, 재계획·초기화 후 저장 결과 해시 불변, 측정 출력의 original+balanced 검증, 올바른 출력 경로의 파일/폴더 열기 요청, 모달 중 dock 숨김, 800/720px 동작의 화면 내 위치, page error 0이다. 결과 합계는 **983,570바이트 < 1,048,576바이트**였다. 합계 한도 위치는 원본 바이트 기반 28.969556956762098%에 대해 CSS 직렬화 28.9696%로, 허용치 0.0001% 이내였다. 표시 단위와 실제 바이트 판정을 혼동하지 않는다.

OS 파일 선택 응답과 결과 열기 자체는 합성 경로/기록용 OS 어댑터로 제어했다. 실제 한컴 실행을 주장하지 않는다. 진행 캡처는 실제 worker의 계산 이후 저장 직전 전달을 잠시 제어해 시간을 확보했다. CPU 단계 강제 취소 검증은 별도 `documentCancellation.test.ts`의 범위다.

로컬 대상 4개 파일·48개 테스트 및 전체 93개 파일·752개 통과·1개 skip, typecheck/build·hygiene·runtime audit를 통과했다. 기존 외부 jpegli 미설치 후보 테스트의 skip이다. 실제 Electron 문서 11개+설정 4개 흐름은 다음 동작의 화면 내 가시성, dock 실행, 명시적 단일 재계획·세부 검증 초기화·기존 결과 보존, dock 초기화와 미완료 결과 제목 이동을 포함한다. Windows와 PR 실행 증거는 [PR #9 검사](https://github.com/eunsang26/hwpx-optimizer/pull/9/checks)에 해당 head별로 남긴다.

## 남은 범위

이미지에서 명확한 다음 행동·표시 의미를 확인했으며, 전체 WCAG/보조기술 호환성을 입증하지 않았다. OPT-024는 모달/진행 포커스·배경 조작 차단·진행 문구와 live status·취소/오류/반복 실행·늦은 요약 보고서 응답을 검증한다. OPT-025는 확대/리플로우, 대비·클릭 크기, 표/긴 파일명, 하단 고정 영역과 본문 동작의 간격·중복을 실제 화면으로 개선한다. 하단의 주 동작은 보이지만 모든 본문 내용이 첫 화면에 들어가도록 보장하지 않는다. 기관 Windows 10/11·한컴·실제 대형 문서/장시간 검증은 OPT-021에 남긴다.
