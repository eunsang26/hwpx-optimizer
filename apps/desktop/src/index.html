      주의할 점

        자동 검증 결과

        최적화 후 문서 구조, 누락 리소스, 이미지 품질 기준을 자동으로 확인합니다.

        분석 결과 대기 중 파일을 선택하면 실행 요약이 표시됩니다.

        이미지 비교

        변경된 이미지를 원본과 결과 썸네일로 비교합니다.

        사용 매뉴얼

        제출용 HWPX 파일을 줄일 때 필요한 순서와 판단 기준입니다.

        1. 1. 파일 선택

          파일 1개를 선택하면 단일 모드로 바로 분석합니다. 파일이나 폴더를 추가해 2개 이상이 되면 일괄 처리 목록으로 전환됩니다.

        2. 2. 분석 결과 확인

          원본 용량, 예상 결과 용량, 예상 절감량, 제출 기준 통과 여부를 먼저 확인합니다. 초록 상태면 현재 기준으로 제출 가능성이 높습니다.

        3. 3. 제출 기준 설정

          기관 기준이 있으면 제출 제한을 직접 입력합니다. 보존 기준은 기본적으로 권장(균형)을 사용하고, 외형 보존이 중요하면 보수(외형)를 선택합니다.

        4. 4. 자동 최적화 계획 확인

          오른쪽 계획 목록에서 적용할 작업을 확인합니다. 체크된 항목만 실행되며, 분석 후 예상 절감량이 항목별로 표시됩니다.

        5. 5. 실행과 저장

          최적화 버튼을 누르면 원본은 그대로 두고 새 HWPX 파일을 저장합니다. 저장 위치를 바꾸지 않으면 원본 문서 폴더에 저장합니다.

        6. 6. 일괄 처리

          목록에서 불필요한 파일은 제거할 수 있습니다. 일괄 목록에 1개만 남으면 단일 모드로 돌아가 세부 옵션을 더 쉽게 조정합니다.

        7. 7. 세부 분석 보기

          하단의 세부 분석 보기를 열면 이미지, 중복 리소스, 메타데이터, 주의 리소스와 자동 검증 결과를 확인할 수 있습니다.

        8. 8. JSON 리포트

          일반 사용에는 필요하지 않습니다. 제출 기록이나 내부 검토용 근거 파일이 필요할 때만 설정에서 JSON 리포트 저장을 켭니다.

        9. 9. 보안 문서 제한

          암호나 권한으로 보호된 문서는 우회하지 않습니다. 파일 내용은 업로드하지 않고 이 PC 안에서만 처리합니다.
