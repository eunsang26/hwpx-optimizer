A안 상세: 단계형 첫 사용 흐름

기존 기능은 유지하고, 처음 쓰는 사람이 다음 행동을 바로 알 수 있게 화면 순서를 재배치합니다.

1 파일
2 분석
3 방식
4 결과

추천 모드 / 선택 모드

흐름

1 파일: 첫 화면은 파일 드롭/선택만 강하게 보입니다. 여러 파일과 폴더는 보조 액션으로 유지합니다.

2 분석: 파일을 고르면 자동 분석하고, 핵심 숫자 3~4개만 먼저 보여줍니다. 세부 차트와 작업 선택은 접거나 아래로 보냅니다.

3 방식: Safe/Balanced/Aggressive는 카드 3개로 유지하되, 추천/주의 문구와 실행 버튼을 같은 영역에 둡니다.

4 결과: 결과 파일 열기, 폴더 보기, 이미지 비교를 가장 눈에 띄게 배치합니다.

구현 범위

1차는 renderer-only에 가깝게 진행합니다. 핵심은 HTML/CSS 구조, 상태 문구, 버튼 우선순위, hidden/visible 전환입니다. core 최적화 로직, IPC, 파일 저장 규칙은 건드리지 않습니다.

검증

기존 desktop smoke가 깨지지 않아야 합니다. 추가로 view-model 또는 renderer smoke assertion에서 단계 헤더와 주요 버튼 렌더링을 확인합니다.
